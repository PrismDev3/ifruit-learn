# iFruit OS — Learn & source links

iFruit OS is an educational browser desktop simulation inspired by the iFruit universe. The static link page lists CDN sources, ESM dependencies, and the live interactive demos.

## CDN and source files

These are file contents, not the interactive app. A CDN may show the HTML source as text; use a hosted demo link below to run it.

- jsDelivr HTML: https://cdn.jsdelivr.net/gh/PrismDev3/ifruit-learn@main/learn-1.html
- jsDelivr SVG: https://cdn.jsdelivr.net/gh/PrismDev3/ifruit-learn@main/learn-1.svg
- jsDelivr wallpaper: https://cdn.jsdelivr.net/gh/PrismDev3/ifruit-learn@main/wallpapers/vice-dusk-1920.webp
- GitHub repository: https://github.com/PrismDev3/ifruit-learn
- GitHub raw HTML: https://raw.githubusercontent.com/PrismDev3/ifruit-learn/main/learn-1.html
- Githack HTML: https://raw.githack.com/PrismDev3/ifruit-learn/main/learn-1.html
- Statically HTML: https://cdn.statically.io/gh/PrismDev3/ifruit-learn/main/learn-1.html

## ESM dependencies

- React: https://esm.sh/react@19.3.1
- React DOM client: https://esm.sh/react-dom@19.3.1/client
- Motion: https://esm.sh/motion@14.14.0/react
- Lucide React: https://esm.sh/lucide-react@1.76.0

These ESM URLs are developer dependencies. The standalone demo already bundles them.
